CSS Components

基于语义令牌（CSS 自定义属性）的轻量组件库 — 总览

库入口为 index.css，它按顺序导入 base、grid、card、flex、list、form、 menu、input、button、select、switch、utils、table、badge、dropdown、navbar、dialog、details、stats、alert。 主题通过 <html data-theme="..."> 显式开启，右侧工具栏可即时切换。

20+ index.css 导入的组件文件
4 内置主题（亮色 / 暗色 / 谷歌 / 粉红）
0 运行时 JS 依赖（演示页除外）
快速上手 查看令牌 →

引入入口样式与一个主题，然后在 <html> 上声明主题即可：

<link rel="stylesheet" href="index.css">
<link rel="stylesheet" href="theme/light.css">
<html data-theme="light">

只在某个子树内生效也是可以的——把 data-theme 放在任意元素上。
