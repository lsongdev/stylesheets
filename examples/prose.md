# Prose：文章排版与站点布局的边界

`prose.css` 负责文字的内部节奏，不负责文章在页面中的位置。
`prose.html` 提供窄栏与全宽两个真实示例，可切换亮色、暗色主题。

## 字体与语言

- 正文使用 Georgia / Times，中文优先思源宋体、Noto Serif，回退到 Songti SC、SimSun。具名字体放在通用 `serif` 前，避免通用字体先接管中文字符。
- 标题和元信息使用系统无衬线字体，字重 600，避免粗宋体的笔画与英文标题重量失衡；可用 `--prose-heading-font-family` 覆盖。
- 正文保留系统原生的笔画渲染，不继承站点的强制灰度平滑。不加载远程字体，具体字形随操作系统与已安装字体变化。
- 请标注真实的 `lang`。中文 `.prose` 的默认行高为 1.85，其他语言为 1.75；中文标题不压缩字距，中文标点使用严格换行规则。混排文章内可单独给英文标题或段落标注 `lang="en"`。
- 连续标题适度收紧间距；段落、引用、列表、代码和表格保留统一节奏。

## 集成示例

```html
<article class="publication prose" lang="zh-CN">
  <header class="prose-header">
    <h1 lang="en">A title in English</h1>
    <p class="prose-meta"><time datetime="2026-09-03">Sep 3, 2026</time></p>
  </header>
  <section>
    <h2>正文标题</h2>
    <p>中文正文与 English 混排。</p>
  </section>
</article>
```

```css
.publication {
  --prose-measure: none;
  margin-top: clamp(44px, 6vw, 72px);
}
```

默认的 `68ch` 适合独立阅读栏；`none` 让正文填满宿主容器，宿主仍应提供合理的页面最大宽度和手机边距。不要在标准库中加入站点导航间距或品牌专属宽度。

`.prose-header` 提供标题、元信息与正文之间的留白，`.prose-meta` 提供较小、低强调度的日期和作者排版。两者是可选类，不影响普通 Markdown 标题。

`--prose-*` 默认值使用低优先级选择器，宿主可以用单个类覆盖字体、行高、段距或宽度；手机断点也遵循这个约定，无需 `!important`。

## 视觉检查

- 宽屏：窄栏保持默认行长，全宽示例与外层容器对齐。
- 390px / 320px：英文长标题自然折行，中英文段落没有页面级横向溢出。
- 连续标题：标题之间的间距小于独立章节之间的间距。
- 长代码和表格：在各自容器内横向滚动，不撑破文章。
- 亮色 / 暗色：标题、正文、元信息、代码和表格使用主题语义颜色。
- 元信息之后的正文：无论从段落还是标题开始，都保留完整的头部间距。
