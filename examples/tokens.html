主题令牌

全局语义 token 控制整体主题，组件 token 只控制单个组件，主题可设在根节点或任意子树

主题通过 data-theme="<名称>" 显式开启。左侧各预览区即为同一页面内的独立主题子树，右侧"分层覆盖"展示局部令牌覆盖。

分层覆盖

品牌色 + 局部组件令牌

推荐覆盖方式

/* 全局语义覆盖 */
:root {
  --color-primary: #7c3aed;
  --color-primary-hover: #6d28d9;
}

/* 只覆盖暗色 */
[data-theme="dark"] {
  --color-surface: #111827;
  --input-border-color: #4b5563;
}

/* 只覆盖一个组件或局部区域 */
.compact-form {
  --input-padding: 6px 9px;
  --input-border-radius: 999px;
}
