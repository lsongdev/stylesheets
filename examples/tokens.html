Design Tokens

全局语义 token 控制整体主题，组件 token 只控制单个组件。主题可以设置在根节点，也可以设置在任意局部容器。

分层覆盖

推荐覆盖方式

/* 全局语义覆盖 */
:root {
  --color-primary: #7c3aed;
  --color-primary-hover: #6d28d9;
}

/* 只覆盖暗色 */
[data-theme="dark"] {
  --color-surface: #111827;
  --input-border-color: #4b5563;
}

/* 只覆盖一个组件或局部区域 */
.compact-form {
  --input-padding: 6px 9px;
  --input-border-radius: 999px;
}

迁移旧变量

legacy.css 集中保存旧变量别名。默认入口仍会加载它；新项目可直接引入 base.css，迁移完成后移除兼容层。
